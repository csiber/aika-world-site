# AIKA World v2.9.1 — Full-Stack Cloudflare Workers + Vue 3 + D1 (STABLE)

**AIKA World** is a modern, real-time galactic strategy game built on the Cloudflare ecosystem (Workers, D1, Assets) using Vue 3.

## Key Improvements (v2.9.1)
- **🎨 Design Polish**: Refined the global UI by softening panel borders and improving background integration. The "white frame" effect has been replaced with subtle, high-tech translucent borders.
- **⚔️ Alliance Wars (v2.9.0)**: Declare war on rival alliances and track scores in real-time.
- **⚖️ Marketplace (v2.8.0)**: Galactic Exchange and NPC Trader for efficient resource management.
- **🖥️ Cyberpunk Onboarding**: Terminal intro and interactive tutorial for new Commanders.
