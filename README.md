# AIKA World v2.3.0 — Full-Stack Cloudflare Workers + Vue 3 + D1

**AIKA World** is a modern, real-time galactic strategy game built on the Cloudflare ecosystem (Workers, D1, Assets) using Vue 3.

## Features (v2.3.0)
- **🤝 Alliance Progression**: Alliances can now level up by collecting experience through member donations. 
- **🏦 Resource Bank & EXP**: Members can donate resources to the Alliance Vault to gain EXP.
- **⚡ Collective Bonuses**: High-level alliances grant passive production bonuses to all their members (+1% metal/crystal/deus production per level).
- **🌌 Expanded Galaxy Map**: Navigate 9 Galaxies and 499 Systems with a redesigned "System View".
