# AIKA World v2.6.0 — Full-Stack Cloudflare Workers + Vue 3 + D1

**AIKA World** is a modern, real-time galactic strategy game built on the Cloudflare ecosystem (Workers, D1, Assets) using Vue 3.

## Features (v2.6.0)
- **🌌 Deep Space Expeditions**: Send your fleets into the unknown (Slot 16) to discover lost resources, abandoned ships, or encounter cosmic phenomena.
- **🎨 Modern UI with Theming**: Fully responsive interface with Light and Dark mode support.
- **🚛 Debris Fields & Recycling**: Harvest wreckage from intense space battles.
- **🤖 NPC Bots v2**: Active AI that scouts and challenges players.
