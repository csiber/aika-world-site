# AIKA World v2.6.1 — Full-Stack Cloudflare Workers + Vue 3 + D1

**AIKA World** is a modern, real-time galactic strategy game built on the Cloudflare ecosystem (Workers, D1, Assets) using Vue 3.

## Features (v2.6.1)
- **📏 Robust Topbar Layout**: Completely refactored the header using CSS Grid to ensure stability across all screen sizes and prevents layout shifting.
- **🌌 Deep Space Expeditions**: Explore Slot 16 for unique rewards or unexpected dangers.
- **🎨 Light/Dark Mode**: Fully functional theme engine with persistent user preference.
- **🚛 Debris & Recycling**: Recover resources from battlefield wreckage.
